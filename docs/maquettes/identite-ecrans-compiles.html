L'état « déconnecté » n'existe plus : plus de « ☁︎ Connexion », plus de libellé variable. Une pastille d'initiale, toujours la même, sur Maison, Cuisine, Nounou et l'app. Elle ouvre la page de compte.

Saisir le code + foyer trouvé
Le trou le plus grave : sans eux, un code d'invitation ne peut être saisi nulle part. Et on ne rejoint pas une maison à l'aveugle — l'écran la nomme avant d'engager.
Un seul motif d'erreur
Cases en rouge + une ligne. Le même motif sert au code invalide, au code expiré et à l'échec d'envoi — trois textes, un dessin. C'est ce qui remplace les écrans hors-ligne abandonnés.
Le bouton compte
Unifié en pastille d'initiale sur ses quatre emplacements.
