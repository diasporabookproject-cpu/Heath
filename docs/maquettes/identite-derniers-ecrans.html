Ce que ces quatre écrans tranchent

Celui qui rejoint ne fait pas la FTUE
Le foyer existe : lui faire choisir des domaines et nommer une équipe n'aurait aucun sens — il écraserait le travail d'Amine. L'écran d'arrivée remplace la FTUE pour lui : il nomme la maison, montre ce qui l'attend, et entre. C'est une bifurcation de parcours, pas une décoration — à écrire dans les décisions.
L'invitation dit quoi faire
Sofia n'a pas l'app. Le message porte donc trois choses : ce que c'est, le code, où installer. Sans le troisième, le code est mort-né.
Le code n'existe pas d'avance
Par défaut : « Inviter quelqu'un ». Le code naît du geste et vit 24 h — plus sain qu'un code permanent qui traîne dans la page de compte.
La suppression s'adapte
Seul, sans page partagée : pas de bloc rouge, pas de liste vide. On ne brandit pas des conséquences qui n'existent pas.
Deux réserves : ① manzil.ma n'est pas acheté — le lien du message est un substitut, et le message est bloqué tant que le domaine (ou les liens de store) n'existent pas · ② l'écran d'arrivée est en DA v2 alors que la suite de la FTUE ne l'est pas encore : la couture se verra chez le fondateur, pas chez le membre.
